# Atlas Logist

Демонстрационный кабинет логиста по презентации проекта. Статический сайт: HTML, CSS, JavaScript. Без реальных API и персональных данных.

## Запуск

Откройте index.html или запустите `python -m http.server 8000` в каталоге проекта.

## GitHub Pages

После загрузки в репозиторий с веткой main выберите Settings → Pages → Source → GitHub Actions. Workflow pages.yml публикует сайт при push в main.

## Сценарии

- Заявки: поиск по демонстрационной выборке.
- Решения: три плана, целевая стоимость и расчёт экономии.
- Мониторинг: статический пример исполнения, без обращения к перевозчикам.

Цены и SLA являются оценками из презентации. Дневной бюджет вычисляется из округлённой цены за точку.
